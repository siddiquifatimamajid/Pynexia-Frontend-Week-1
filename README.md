**Pynexia Frontend Development — Week 1**

**Overview**

This repository contains projects developed as part of the Pynexia Frontend Development Internship, Week 1.

The week's learning focuses on core frontend development concepts, including responsive layouts, DOM manipulation, JavaScript event handling, and interactive user interfaces.

**Week 1 Projects**

**1. Dynamic Toggle Navigation**

Difficulty: Easy
Status: Completed

An interactive and responsive navigation interface featuring:

- Responsive desktop navigation bar
- Mobile hamburger menu
- Animated menu opening and closing
- Interactive navigation links
- Hover and active link states
- Keyboard interaction using the Escape key
- Responsive desktop and mobile layouts

Technologies: HTML5, CSS3, JavaScript

Project location: "Dynamic-Toggle-Navigation/"
